## ⚡ 3. Quick Technical Screening Q&A (Kalkani Systems Focus)

### Q1: "What are React Hooks and why do we use them?"
> **Answer:** "Hooks were introduced in React 16.8 to allow functional components to manage state and lifecycle side-effects without writing class components. Common hooks include `useState` for local component state, `useEffect` for handling asynchronous side effects and subscriptions, `useMemo` to memoize expensive computations, and `useCallback` to cache function references to prevent unnecessary child re-renders. We also write custom hooks to encapsulate reusable stateful business logic across components."

### Q2: "How do you optimize a React application that is running slow?"
> **Answer:** 
> 1. **Component Re-render Optimization:** Using `React.memo`, `useMemo`, and `useCallback` to prevent cascading renders.
> 2. **Code-Splitting & Lazy Loading:** Leveraging `React.lazy()` and `Suspense` with dynamic `import()` to split bundles and load route chunks on-demand.
> 3. **Asset & Bundle Optimization:** Using modern bundlers like Vite 6, minifying CSS (Tailwind v4), and optimizing images.
> 4. **Virtualization:** For long lists, using virtual windowing (like react-window) to only render DOM elements within the visible viewport.
> 5. **Profiling:** Inspecting bottlenecks using Chrome DevTools Performance tab and React DevTools Profiler (which I used at Amnesea to achieve a 35% latency drop).

### Q3: "How do you handle API calls and errors in React?"
> **Answer:** "I use `useEffect` or data-fetching abstractions with `async/await` and `fetch`/`axios`. I structure state with `data`, `isLoading`, and `error` flags. For unexpected UI crashes, I wrap components with React **Error Boundaries** to render user-friendly fallback states rather than breaking the entire web page."

### Q4: "What is your approach to converting Figma / UI designs into responsive code?"
> **Answer:** "I follow a **mobile-first approach** with Tailwind CSS utility classes or responsive CSS grid/flexbox. I define consistent design tokens (colors, typography, spacing) early on, break down the UI into atomic, reusable components (buttons, cards, inputs, modals), and test across distinct breakpoints (mobile <640px, tablet 768px, desktop 1024px+) to guarantee cross-device fidelity."
