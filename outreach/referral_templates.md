# High-Conversion Referral Message Templates

Use these 3-sentence messages when reaching out on LinkedIn to engineers (SDE-1, SDE-2, Alumni from IPS Academy) at companies you are applying to:

---

### Template 1: For General SDE / Full-Stack Roles
> *"Hi [First Name], hope you're doing well! I'm a 2025 CSE graduate from IPS Academy and I recently saw an opening for SDE-1 (Req ID: [Job ID]). I’ve engineered a sub-millisecond UDP peripheral ecosystem (<1ms latency with Win32 SendInput) and a commercial React 19/TypeScript e-commerce platform. Here is my 1-page resume: [Google Drive / Portfolio Link]. Would you be open to providing a quick referral? Truly appreciate your time!"*

---

### Template 2: For Systems / Backend / Low-Latency Roles
> *"Hi [First Name], I came across your profile and love the engineering work being done at [Company]. I’ve built an open-source wireless peripheral system that bypassed TCP head-of-line blocking using custom UDP datagram streaming over Port 5002 to achieve <1ms cursor injection. I'm applying for the [Role Name] position (Job ID: [Job ID]). Could I share my resume for a quick referral? Thank you!"*

---

### Template 3: For Frontend / React Engineering Roles
> *"Hi [First Name], I noticed [Company] is hiring for a Frontend Engineer. I’ve built production applications using React 19, TypeScript 5.8, and Tailwind CSS v4, including a commercial gifting showroom with automated concierge pipelines and lookbook print engines. Here is my portfolio and 1-page resume: [Link]. Would you be willing to refer me for this opening? Thanks so much!"*

---

### Best Practices:
1. Always attach the exact **Job ID** and **Job Title**.
2. Make sure your Google Drive resume link has permissions set to **"Anyone with link can view"**.
3. Send requests Tuesday–Thursday between 9:30 AM and 11:30 AM local time for highest open rates.
